# Android 9 emulator captures

Unedited screenshots from the Android API 28 Google APIs emulator, captured by the compatibility instrumentation in GitHub Actions run 40083004417 at application commit 94f78dfdbb06a92b609fd1d895614bb6ceb550f0.

- cinematic.png: Home with the All Apps fallback; this emulator has no streaming services installed.

Weather and recommendations are disabled for deterministic, offline UI checks. Phone emulator navigation controls are visible; these are not screenshots of the Mi TV or proof of measured device performance. These images are documentation only and are not bundled in the APK.
